# Blue Peak — Foreclosure Guide Bridge Page (mockup)

A single-file, customer-facing **mockup** of a "bridge page" for the SC Foreclosure Timeline lead magnet:
guide content on-page + a founder video placeholder + an interactive (faked) booking calendar, designed to
turn a "yes, send me the guide" reply into a booked call.

- **Purpose:** review/demo only — not a live page. Placeholder logo, illustrative founder video and outcome
  stories, masked phone number. Real guide copy is Blue Peak Solutions' SC Foreclosure Timeline.
- **Stack:** one self-contained `index.html` (inline CSS/JS, no dependencies, no backend).
- **Live preview:** served via GitHub Pages.
